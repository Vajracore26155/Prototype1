HOW TO USE:
================================================================================

1. Start Backend:
   cd backend
   python -m uvicorn app.main:app --host 127.0.0.1 --port 8003 --workers 1

2. Register Vendor:
   - POST /api/vendor/register
   - Admin receives notification email

3. Admin Approves:
   - POST /api/admin/vendor-requests/{id}/decide
   - Vendor receives approval email

4. Vendor Requests OTP:
   - POST /api/vendor/request-otp
   - Vendor receives OTP code via EMAIL

5. Vendor Verifies OTP:
   - POST /api/vendor/verify-otp
   - Session created (valid for 24 hours)

6. Vendor Sets Password:
   - POST /api/vendor/set-password
   - Password hashed and stored

7. Vendor Logs In:
   - POST /api/vendor/login (email + password)
   - Session created for file upload
