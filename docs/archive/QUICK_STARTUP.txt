================================================================================
🚀 QUICK STARTUP - BACKEND & FRONTEND
================================================================================

OPEN TWO TERMINALS:

================================================================================
TERMINAL 1 - BACKEND
================================================================================

Command:
    cd backend
    python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1

Expected Output:
    INFO:     Uvicorn running on http://127.0.0.1:8000
    [SUCCESS] Database initialized successfully
    [STARTUP] Application ready!

What It Does:
    - Starts REST API server on port 8000
    - Initializes SQLite database
    - Loads environment configuration
    - Activates email service (Gmail SMTP)
    - Ready to receive API requests

================================================================================
TERMINAL 2 - FRONTEND
================================================================================

Command:
    cd frontend
    npm run dev

Expected Output:
    ➜  Local:   http://localhost:5173/
    ➜  press h to show help

What It Does:
    - Starts React development server on port 5173
    - Hot reload enabled (auto-refresh on code changes)
    - Connects to backend API on port 8000
    - Webpack build in memory
