IF IT STILL FAILS
================================================================================

Error: "ECONNREFUSED 127.0.0.1:9000"
  → Backend is not running
  → Solution: Start backend (see IMMEDIATE ACTION above)

Error: "Port 9000 already in use"
  → Old backend still running
  → Solution: taskkill /F /IM python.exe

Error: "Port 5173 in use"
  → Old frontend still running
  → Solution: taskkill /F /IM node.exe

Error: "npm not found"
  → Node.js not installed
  → Solution: Install from https://nodejs.org/

Error: "ModuleNotFoundError"
  → Dependencies not installed
  → Solution: cd backend && pip install -r requirements.txt
