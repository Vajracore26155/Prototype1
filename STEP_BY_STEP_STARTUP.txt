================================================================================
TROUBLESHOOTING DURING STARTUP
================================================================================

ISSUE: "Port 8000 already in use"
SOLUTION:
   a) Close other applications using port 8000
   b) Or use different port: --port 8001 instead

ISSUE: "npm command not found"
SOLUTION:
   a) Install Node.js from https://nodejs.org/
   b) Restart terminal after installation
   c) Retry npm run dev

ISSUE: "ModuleNotFoundError" (Python)
SOLUTION:
   a) Run: pip install -r requirements.txt
   b) Wait for installation to complete
   c) Retry the uvicorn command

ISSUE: Can't connect to http://localhost:5173
SOLUTION:
   a) Check if frontend terminal shows "Local: http://localhost:5173"
   b) Wait 5-10 seconds for frontend to fully load
   c) Refresh browser page (Ctrl+R)

ISSUE: Login fails with admin credentials
SOLUTION:
   a) Verify backend is running (should see messages in terminal 1)
   b) Check network connection
   c) Verify .env file has correct database path
